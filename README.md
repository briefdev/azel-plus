# azel

ثيم متجر **عازل بلس** (azel-sa.com) — صفحات ستاتيك تمهيداً لتحويلها إلى ثيم سلة (Twilight).

## الصفحات
| الملف | الصفحة |
|---|---|
| `index.html` | الرئيسية |
| `shop.html` | التصنيف |
| `product.html` | المنتج المفرد (اختيار درجة التظليل لكل جهة) |
| `cart.html` | السلة |
| `checkout.html` | إتمام الطلب (مرجع تصميم — الدفع في سلة تديره المنصة) |
| `centers.html` | مراكز التركيب المقترحة |

## الملفات المشتركة
- `assets/css/style.css` — الهوية والمكوّنات (الأخضر `#014D3C` والليموني `#C8E115`).
- `assets/js/main.js` — الهيدر والفوتر وبيانات المنتجات والدرجات والسلة. إعدادات المتجر في `STORE` أعلى الملف.
- `assets/js/faq.js` — الأسئلة الشائعة.

افتح `index.html` مباشرة في المتصفح للمعاينة.
