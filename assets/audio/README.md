# التقييمات الصوتية

1. ارفع الملف الصوتي هنا (يفضّل mp3 أو m4a، وأقل من 2 ميجا).
2. أضف سطراً في `VOICE_REVIEWS` أعلى ملف `assets/js/main.js`:

```js
{ name: "اسم العميل", city: "الرياض", product: "car-film", rating: 5, file: "assets/audio/اسم-الملف.mp3" },
```

`product` معرّف المنتج (مثل `car-film` أو `bt13`) ويظهر كرابط تحت الاسم، ويمكن حذفه.
